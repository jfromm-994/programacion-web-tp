GameVault

GameVault es una aplicación web diseñada para gestionar un catálogo personal de videojuegos. Permite registrar títulos, hacer seguimiento del progreso de juego (Pendiente, Jugando, Completado), calificar experiencias y clasificar por plataforma.

Estructura de Datos (Entidad Juego)

  • Título: Nombre del juego.
  • Plataforma: PC, PlayStation, Xbox, Switch, etc.
  • Género: Acción, RPG, Estrategia, etc.
  • Estado: Pendiente, Jugando, Completado, Abandonado.
  • Puntaje: Calificación personal del 1 al 10.
